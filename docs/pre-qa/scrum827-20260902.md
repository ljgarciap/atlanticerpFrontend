# Pre-QA — SCRUM-827 (2026-09-02)

Vista de solo lectura de `legacy.pagos` (TESORERIA), catálogo standalone sin cliente, épica
SCRUM-749. Gate `role:superadmin` exclusivo (más restrictivo que el dashboard de SCRUM-816, que
también admite `management`) — audiencia solo equipo técnico, confirmado por Luis en el comentario
del ticket 2026-09-02.

## Corrido en LOCAL contra `http://localhost:8090`, no `dev.atlanticerp.ai`

Mismo criterio que el resto de specs de Pre-QA del proyecto. `legacy.pagos` no tiene endpoint de
escritura (staging de solo lectura, sin Loader-B ni Matcher) — se sembraron 25 filas manualmente
vía tinker antes de la corrida (después del último `infra/test.sh` de la sesión, evitando el
gotcha conocido de Postgres compartido), cubriendo los 4 `estado` (S/P/C/X), los 3 `icg_origen`
(C/E/P), los 4 `icg_tipodocumento` (A/E/F/P), un importe negativo, y la fecha centinela real
documentada en el ticket (`9202-04-02`).

## Escenarios de ruptura intentados

| Escenario | Resultado |
|---|---|
| `management` intenta ver el Sidebar/URL directa | Ítem "Pagos ICG" ausente del Sidebar; navegación directa a `/migracion/pagos` no muestra la pantalla (bloqueada por `RequireRole`) — pero SÍ ve "Migración ICG" (SCRUM-816), confirmando que el gate es específicamente más angosto para este ticket, no un error de configuración |
| `designer` intenta ver el Sidebar/URL directa | Sección "Migración" completa ausente; URL directa bloqueada |
| Filtro por `estado=X` (código real, sin hipótesis confirmada) | Se filtra correctamente por el código crudo; la celda muestra `X`, nunca "Anulado/excepción" (la hipótesis vive solo en el tooltip) |
| Combinación de filtros `icg_origen=P` + `icg_tipodocumento=A` | AND correcto — solo la fila que matchea ambos |
| Importe negativo (`-120.50`) | Se muestra tal cual, sin ocultar ni crashear |
| Filtro de fecha que no descarta la fecha centinela `2202-12-12` (probado con `fecha_desde=2099-01-01`) | El backend compara la fecha centinela como fecha real (no la trata como NULL/especial) — un filtro "futuro" ingenuo no la excluye. Ajusté el test para usar `9300-01-01` como caso realmente vacío. **No es un bug**: es el comportamiento correcto dado que el diseño decidió mostrar las fechas centinela tal cual, nunca ocultarlas — pero es una nota útil para QA formal, por si el criterio de "filtrar por rango" se interpreta con expectativas distintas |
| Estado sin resultados (`fecha_desde=9300-01-01`) | Estado vacío explícito ("Sin registros para este filtro."), no error ni pantalla en blanco |
| Botones de crear/editar/eliminar/guardar | Ausentes — la pantalla es de solo lectura como exige el AC |
| Paginación (25 filas sembradas, 20/página) | Página 1 con 20 filas, "Siguiente" avanza a 5 filas restantes, "Anterior" vuelve — sin errores en los bordes |
