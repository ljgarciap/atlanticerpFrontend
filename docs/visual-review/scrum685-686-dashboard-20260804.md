## Nota sobre el ítem 5 (duplicación de tarjetas)

Se confirmó explícitamente contra el mockup real (`mockup.html` descargado de attachment 11535)
que el mockup **sí** contiene el bloque duplicado de 2 tarjetas grandes ("Pipeline activo" /
"Cerrado (ganado)") debajo de los gráficos — coincide con lo que dijo el Arquitecto el 04/08. La
regla de este gate (`visual-reviewer.md`) trata cualquier ausencia de un elemento del mockup como
CRÍTICO por default — pero acá hay una decisión explícita y documentada de Luis (comentario Jira
2026-08-04 17:59) que autoriza el desvío como cambio de alcance, exactamente el mecanismo que la
regla de decisión pide ("ante la duda... que PM/Luis decidan" — ya decidieron). Se documenta como
**excepción aprobada, no como hallazgo.**
